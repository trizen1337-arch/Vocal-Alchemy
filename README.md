# Vocal Alchemy

An open-source, Android-first mobile multitrack recording and vocal-production workstation.

## Project status

Early alpha / Android migration planning. No APK release is available yet.

## Goals

- Offline-first multitrack editing and recording
- Touch-friendly arrangement, mixer, lyrics, and take-comping workflows
- Punch-in recording, monitoring, metronome, and latency calibration
- Local project storage and portable backups
- Native Android audio capture and routing, while retaining the existing web-based DAW UI during migration

## Development plan

1. Establish Android Gradle project and GitHub Actions debug APK builds.
2. Integrate the existing Vocal Alchemy DAW UI into the Android app shell.
3. Implement native microphone capture, headphone-route detection, and monitoring safeguards.
4. Improve synchronization, punch-in recording, take management, and calibration.
5. Validate recording, playback, save/restore, and export on Android devices.

## Contributing

The project is being prepared for contributions. Build instructions and contribution guidance will be added with the Android project.
